当前风控规则说明

止损：当持仓浮亏达到止损比例时，立即全部卖出，防止进一步亏损

止盈：当持仓浮盈达到止盈比例时，立即全部卖出，锁定利润

移动止损：以持仓期间最高价为基准，回落超过比例时卖出，适合趋势行情

最大回撤：账户总资产从峰值回撤超过比例时，强制全部平仓

仓位管理：根据风控参数自动计算每次开仓数量，避免过度集中

推送配置说明

飞书（推荐）：创建飞书群 → 添加自定义机器人 → 复制 Webhook 地址。支持富文本卡片消息，稳定可靠

Server酱：注册 sct.ftqq.com → 获取 SendKey → 免费推送到微信

钉钉：钉钉群 → 智能群助手 → 添加自定义机器人 → 复制 Webhook

企业微信：企业微信群 → 群机器人 → 添加 → 复制 Webhook 地址

邮件：需填写 SMTP 服务器、发件邮箱和授权码（QQ邮箱在 设置→账户 中获取）
